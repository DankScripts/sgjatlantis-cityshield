# Installation

## Requirements

| | Forge | NeoForge |
|:--|:--|:--|
| Minecraft | 1.20.1 | 1.21.1 |
| Loader | Forge 47.4.16 build | NeoForge 21.1.219 or newer compatible 21.1.x |
| Java | 17 | 21 |
| Required mod | Stargate Journey 0.6.50 or newer compatible 1.20.1 release | Stargate Journey 0.6.50 or newer compatible 1.21.1 release |

Use the City Shield and Stargate Journey files matching your Minecraft version and loader. Install matching mods on the server and connecting clients, and keep only one City Shield jar in each `mods` folder. The 1.0.4 builds were made against Stargate Journey 0.6.55-alpha.

{: .warning }
Changing from Forge 1.20.1 to NeoForge 1.21.1 is not a certified world conversion. Back up your world before changing game versions or loaders.
